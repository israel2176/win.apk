# Security

Please don't report security problems in a public issue. Use GitHub's private
reporting instead: the repository's **Security** tab, then **Report a
vulnerability**. Say what you found and how to reproduce it.

Keep in mind how Win.apk works: an Android app running under Win.apk is
ordinary code with your Windows user account's permissions. There is no
phone-style sandbox around it, so "an APK can read my files" is expected
behaviour, not a bug. Only install APKs you trust.
